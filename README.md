## Overview

An Everforest-inspired Oh My Posh theme set with matching dark and light variants.

## Files

- `everforest_dark.omp.json` - dark theme
- `everforest_light.omp.json` - light theme

## Usage

1. Download the theme JSON you want to use.
2. Place it somewhere on your machine.
3. Point Oh My Posh to that file in your shell profile, see [official documentation](https://ohmyposh.dev/docs/installation/customize) for details.
